# Wasowo — E-Commerce Storefront UI

Prototype struktur aplikasi berdasarkan E-Commerce Storefront UI Page Architecture V1.1.

## Scope
- Struktur AppShell, Standalone, dan Overlays.
- Page dan komponen berupa placeholder sederhana.
- Footer digunakan satu kali per layout.
- Belum mencakup fitur bisnis, backend, atau desain final.
